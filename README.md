# ระบบจดวันลาทีมงาน — ธันวาคม 2569

เว็บแอปเล็ก ๆ สำหรับให้ทีมจดวันลาเดือนธันวาคม โดยจัดสรรไม่ให้ลาชนกันจนไม่มีคนทำงาน

## ใช้งาน

```bash
python server.py 8777
```

แล้วเปิด <http://localhost:8777> ใช้ไลบรารีมาตรฐานของ Python ล้วน ไม่ต้องติดตั้งอะไรเพิ่ม

## ความสามารถ

- **โปรไฟล์สมาชิก** — ชื่อ ตำแหน่ง และจำนวนวันลาคงเหลือของแต่ละคน
- **เตือนเมื่อลาซ้อนกัน** — ไม่มีการตั้งค่าและไม่บล็อกการลา จดได้เสมอ
  แต่ถ้าวันนั้นมีคนลาอยู่แล้ว จะแจ้งทันทีว่าซ้อนกับใคร มีตารางรวม "วันที่ลาซ้อนกัน"
  และปฏิทินจะไล่สีตามจำนวนคนลา ให้ทีมตกลงกันเองว่าจะให้ใครเลื่อน
- **เตือนเมื่อเกินโควตา** — ถ้าวันลาคงเหลือไม่พอก็ยังจดได้ แต่ขึ้นป้ายเตือนในตารางสรุป
- **ลาครึ่งวัน** — เลือกได้เป็นเต็มวัน / ครึ่งเช้า / ครึ่งบ่าย หักโควตา 0.5 วัน
  และนับคนชนกันแยกช่วงเช้ากับบ่าย คนละครึ่งวันจึงลาวันเดียวกันได้
- **ปฏิทินรายเดือน** — เห็นทั้งเดือนในหน้าเดียว แต่ละช่องบอกจำนวนคนลาและชื่อคนลา
  เขียว = 1 คน, เหลือง = 2 คน, แดง = ตั้งแต่ 3 คน เสาร์–อาทิตย์และวันหยุดนักขัตฤกษ์กดไม่ได้
- **สรุปรายคน** — โควตา ใช้ไป คงเหลือ และวันที่ลาทั้งหมด

## การเก็บข้อมูล

ระบบเลือกที่เก็บให้อัตโนมัติ 3 แบบ เรียงตามลำดับ

### 1. ข้อมูลกลางบน GitHub (ใช้ร่วมกันทั้งทีม)

ทุกคนอ่าน-เขียนไฟล์ `data.json` ไฟล์เดียวกันบน repo ผ่าน GitHub Contents API
ไม่ต้องมีเซิร์ฟเวอร์ของตัวเอง จะเปิดหน้าเว็บจากเครื่องไหนหรือผ่าน GitHub Pages ก็ได้

ตั้งค่าที่การ์ด **ข้อมูลกลางบน GitHub** ในหน้าเว็บ ทุกคนกรอก repo / branch / ชื่อไฟล์ ชุดเดียวกัน
แล้วใส่ GitHub token ของตัวเองที่มีสิทธิ์ **Contents: read and write** บน repo นั้น

- token เก็บอยู่ในเบราว์เซอร์ของแต่ละคน ไม่ถูกส่งไปที่ไหนนอกจาก GitHub
- ดึงข้อมูลใหม่ให้อัตโนมัติทุก 30 วินาที
- ถ้ามีคนบันทึกแทรกเข้ามา ระบบจะรวมข้อมูลให้เอง (union ตาม id)
  ส่วนที่ถูกลบจะจำไว้ใน `deleted` เพื่อไม่ให้ฟื้นกลับมา แล้วลองบันทึกใหม่สูงสุด 4 ครั้ง

> **ข้อมูลวันลาเป็นข้อมูลพนักงาน** ควรเก็บใน repo แบบ **private** เท่านั้น
> ถ้าชี้ไปที่ repo สาธารณะ ระบบจะขึ้นคำเตือนให้

### 2. ไฟล์ในเครื่องผ่าน server.py

`server.py` บันทึกลงไฟล์ `data.json` อัตโนมัติทุกครั้งที่มีการแก้ไข

- เขียนแบบ atomic (เขียนไฟล์ชั่วคราวให้เสร็จก่อนแล้วสลับทับ) ไฟฟ้าดับกลางคันไฟล์เดิมไม่พัง
- สำรองเวอร์ชันก่อนหน้าไว้ในโฟลเดอร์ `backups/` เก็บ 20 ชุดล่าสุด

### 3. เบราว์เซอร์เครื่องเดียว

ถ้าเปิด `index.html` ตรง ๆ และยังไม่ได้ตั้งค่า GitHub ระบบจะเก็บไว้ใน localStorage ของเครื่องนั้น
พร้อมขึ้นแถบสถานะสีเหลืองเตือนว่าคนอื่นไม่เห็นข้อมูลนี้

ทั้ง `data.json` และ `backups/` ไม่ถูกเก็บขึ้น repo เพราะเป็นข้อมูลจริงของทีม

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บทั้งหมด (HTML + CSS + JS ในไฟล์เดียว ไม่มี dependency) |
| `server.py` | เสิร์ฟหน้าเว็บ และ API อ่าน/เขียน `data.json` |
| `.claude/launch.json` | ค่าตั้งต้นสำหรับสั่งรันเซิร์ฟเวอร์ |

## ปรับแต่ง

แก้ค่าที่ส่วนบนของสคริปต์ใน `index.html`

- `YEAR` / `MONTH` — เดือนที่ใช้งาน
- `HOLIDAYS` — วันหยุดนักขัตฤกษ์ของเดือนนั้น
